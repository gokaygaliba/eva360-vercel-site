# Eva360 Dijital — V2

Premium dark one-page website built with HTML, CSS and vanilla JavaScript.

## Deploy to Vercel
1. Upload the contents of this folder to the root of your GitHub repository (index.html must be at root).
2. In Vercel choose **Add New → Project** and import the repository.
3. Framework Preset: **Other**. Build Command: empty. Output Directory: empty. Install Command: empty.
4. Deploy.

## Design notes
- Apple-inspired system font stack (SF Pro on Apple devices; system sans-serif fallback elsewhere).
- Generated visual asset in `assets/glass-orb.jpg`.
- Scroll reveal, progress indicator, pointer parallax and CSS 3D glass layers.
- No paid theme, framework or build step required.

## Contact
Update `merhaba@eve360dijital.com` in `index.html` if needed.
