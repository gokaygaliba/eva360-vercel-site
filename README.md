# Eva360 Dijital — Vercel Static Site

Bu paket, Eva360 Dijital için hazırlanmış statik HTML/CSS/JS web sitesi taslağıdır.

## Vercel'e yükleme
1. ZIP dosyasını bilgisayarınızda açın.
2. İçindeki `index.html`, `assets/` ve `vercel.json` dosyalarını bir GitHub deposuna yükleyin.
3. Vercel'de **Add New → Project** seçin ve GitHub deposunu bağlayın.
4. Framework Preset: **Other** seçin.
5. Build Command ve Output Directory alanlarını boş bırakın (veya Output Directory için `.` kullanın).
6. Deploy'a basın.
7. Domain ayarlarından `eve360dijital.com` alan adını Vercel'e bağlayın.

## Özelleştirme öncesi
- İletişim e-postasını `index.html` içinde kontrol edin.
- Telefon ve WhatsApp bağlantısı eklenmedi; gerçek numara sağlandığında eklenebilir.
- Referans/proje logoları ve gerçek müşteri başarı metrikleri henüz eklenmedi.
- Bu paket WordPress teması değil, Vercel'de yayınlanabilen bağımsız statik web sitesidir.
