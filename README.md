# Eva360 Dijital — Vercel'e hazır statik web sitesi

## İçerik
- `index.html`: Ana sayfa ve SEO/OG meta etiketleri
- `style.css`: Responsive tasarım, animasyonlar ve bileşen stilleri
- `script.js`: Mobil menü, scroll reveal ve ilerleme çubuğu
- `vercel.json`: Vercel yapılandırması

## Vercel'de yayınlama
1. ZIP'i açın.
2. Dosyaları bir GitHub deposuna yükleyin.
3. Vercel'de **Add New → Project** seçin ve GitHub deposunu bağlayın.
4. Framework Preset: **Other** seçin.
5. Build Command ve Output Directory alanlarını boş bırakın.
6. Deploy'a basın.

Alternatif: Vercel CLI kuruluysa proje klasöründe `vercel` komutunu çalıştırın.

## Yayın öncesi kontrol
- `merhaba@eva360dijital.com` adresinin aktif olduğundan emin olun.
- Sosyal medya hesapları ve gerçek telefon/WhatsApp numarası eklenebilir.
- Portföy alanındaki görseller konsept mockup'tır; gerçek müşteri referansı değildir.
- Alan adını Vercel Project → Settings → Domains bölümünden bağlayın.

Bu paket statik HTML/CSS/JS kullanır; npm kurulumu veya build adımı gerektirmez.
