# Eva360 Dijital

Statik HTML, CSS ve JavaScript ile hazırlanmış, Vercel üzerinde doğrudan yayınlanabilen web sitesi.

## Yayınlama

Bu klasördeki dosyaları GitHub deposunun kök dizinine yükleyin. Vercel ayarları:
- Framework Preset: Other
- Root Directory: `./`
- Build Command: boş
- Output Directory: boş
- Install Command: boş

Build gerektirmez. `index.html` kök dizinde bulunmalıdır.
